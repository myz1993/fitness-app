Add Food Flow

  • User types in search bar → query sent to Open Food Facts API (debounce 400ms)
  • Results display: food name + kcal/100g + "+ Add" button
  • Tapping "+ Add" opens a gram input modal/bottom sheet
  • System calculates: kcal = (kcal_per_100g / 100) × grams
  • Entry appended to daily log; goal banner and ring update immediately

11
Goal Calculation Formulas

BMR — Mifflin-St Jeor Equation

Female: BMR = (10 × weight_kg) + (6.25 × height_cm) − (5 × age) − 161
Male:   BMR = (10 × weight_kg) + (6.25 × height_cm) − (5 × age) + 5
Other:  Use female formula as default

TDEE

TDEE = BMR × activity_multiplier

Daily Calorie Goal

Calorie goal = TDEE − 500

−500 kcal/day produces ~0.5 kg/week loss — the safe, medically recommended rate.

Daily Water Goal

Water goal (ml) = weight_kg × 33

Progress Percentage

Progress % = Math.round((amount_consumed / daily_goal) × 100)

Always apply Math.round() before rendering to prevent floating-point display artifacts.

All goals are computed once on Profile Setup save and stored to the user record. Diet Log and Water Log read from the stored values — do not recalculate on every screen render.

12
Interaction & State Rules

Real-time Updates

The following must update immediately (no reload) when data changes:

  • Diet goal banner — Target / Consumed / Remaining
  • Diet progress ring — percentage and arc length
  • Water progress ring, arc, and horizontal bar
  • Home Dashboard card values and their progress bars
  • Home hero card "Lost kg" value — on every new weight entry

Progress Ring Animation

TriggerAnimation
Page loadArc animates 0% → current value over 600ms, ease-out
New entry addedArc animates current → new value over 300ms, ease-out

Color Threshold Logic (shared — Diet & Water rings)

if progress < 85%   → module primary color (green or blue)
if progress < 100%  → amber #BA7517
if progress >= 100% → red #E24B4A  +  "Goal reached!" badge

Empty States

ScreenMessage
Diet Log"No food logged today. Tap the search bar to add your first meal."
Exercise Log"No exercise logged today. Search an activity to get started."
Weight Log"No weight logged today. Enter your current weight above."
Water LogRing at 0%, bar empty, all quick-add buttons active

Data Persistence

  • All entries keyed by user_id + ISO date string (e.g. u123_2026-05-17)
  • Home Dashboard always reflects the current calendar day
  • History lists in reverse chronological order (newest first)
  • On new weight entry: update both the weight log and profile.current_weight
