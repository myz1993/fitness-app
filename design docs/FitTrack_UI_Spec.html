Goal Calculation Formulas

BMR — Mifflin-St Jeor

Female: BMR = (10 × weight_kg) + (6.25 × height_cm) − (5 × age) − 161
Male:   BMR = (10 × weight_kg) + (6.25 × height_cm) − (5 × age) + 5
Other:  Use female formula as default

TDEE & Calorie Goal

TDEE         = BMR × activity_multiplier
Calorie goal = TDEE − 500

−500 kcal/day = ~0.5 kg/week loss — safe, medically recommended rate.

Water Goal & Progress

Water goal (ml) = weight_kg × 33
Progress %      = Math.round((consumed / goal) × 100)

Compute goals once on Profile Setup save. Store to user record. All screens read from the stored value.

Interaction & State Rules

Sidebar Toggle Spec

PropertyValue
Collapsed width36px — icons only
Expanded width128px — icons + labels
Width transition220ms ease
Label fade-inopacity 150ms ease, delay 60ms
TriggerClick ☰ button at top of sidebar
PersistenceSave state to localStorage so it survives page reload

Real-time Updates

  • Diet goal banner — Target / Consumed / Remaining
  • Diet progress ring — percentage and arc
  • Water ring, arc, and horizontal bar
  • Home Dashboard — all four card values and progress bars
  • Home hero card "Lost kg" — on every new weight entry

Progress Ring Color Thresholds

if progress < 85%   → module primary color (green or blue)
if progress < 100%  → amber #BA7517
if progress >= 100% → red #E24B4A  +  "Goal reached!" badge

Mobile vs Desktop Layout

ScreenMobileDesktop
NavigationBottom tab bar (3 items)Left sidebar — collapsed (icons, 36px) by default, click ☰ to expand (128px + labels)
Login / SetupSingle columnSplit panel — no sidebar on auth screens
Home2×2 card grid1×4 card row + greeting header
Diet / ExerciseStacked verticalSearch+log left, ring right
WeightStacked verticalLog+history left, progress ring right
WaterStacked verticalRing+bar left, add buttons+log right

Empty States

ScreenMessage
Diet Log"No food logged today. Tap the search bar to add your first meal."
Exercise Log"No exercise logged today. Search an activity to get started."
Weight Log"No weight logged today. Enter your current weight above."
Water LogRing at 0%, bar empty, all quick-add buttons active

Data Persistence

  • All entries keyed by user_id + ISO date (e.g. u123_2026-05-17)
  • Home always reflects the current calendar day
  • History lists: reverse chronological, newest first
  • On weight entry save: update log and profile.current_weight
