### 2. Design Patterns Learning Approach
- Focus on understanding concepts rather than memorizing patterns
- https://www.geeksforgeeks.org/system-design/software-design-patterns/
- Key goals:
  - Understand design patterns vs architecture patterns
  - Explain a few core patterns clearly
- Suggested approach:
  - Create mind maps
  - Deep dive into a small set of important patterns

### 3. Markdown & Mermaid Diagrams
- Use Markdown as the primary documentation format
- Use Mermaid diagrams for:
  - Design patterns
  - Architecture and flow diagrams
- Diagrams can be generated via AI from sketches or screenshots

### 4. React & Project Direction
- Courses (e.g. Udemy) are good for learning React basics
- Project work should:
  - Encourage independent decision-making
  - Avoid over-reliance on AI
- Focus on senior-level thinking and trade-off decisions

### 5. Potential Project Idea

- Features discussed:
  - Food photo upload
  - Calorie tracking
  - Gym activity tracking
  - Height, weight, BMI
- MVP approach:
  - Simple UI
  - Manual data entry + image upload
- Stretch goal:
  - AI image recognition for calorie estimation
